# De Gouden Stap

Een eenvoudige, aanpasbare webshop voor GitHub Pages.

## Aanpassen
- **Producten, prijzen en afbeeldingen:** `products.js`
- **Teksten/structuur:** `index.html`
- **Kleuren en vormgeving:** `style.css`
- **Winkelmandje en filters:** `script.js`

## GitHub Pages
1. Maak een nieuwe GitHub repository.
2. Upload alle vier bestanden.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Sla op. GitHub geeft daarna je website-adres.

De huidige productprijzen zijn voorbeeldprijzen. Vervang ze in `products.js` door jullie echte prijzen. De afbeeldingen zijn voorbeeldafbeeldingen; vervang de `image`-URL per product door jullie eigen productfoto's.
